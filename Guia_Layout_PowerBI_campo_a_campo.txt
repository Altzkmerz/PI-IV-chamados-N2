0) CARREGAR OS DADOS
================================================================
1. Power BI Desktop → Obter dados → Excel.
2. Selecione Chamados_N2_com_predicao.xlsx.
3. Marque só a aba Chamados_com_score → Transformar dados.
4. No Power Query, ajuste tipos:
   - Id Chamado Qualitor          → Texto
   - Titulo, Categoria, Prioridade, Status, Razao do Status → Texto
   - Data criacao, Data resolucao → Data
     (se vier como texto dd/mm/aaaa: coluna → Data → Usar localidade → Português Brasil)
   - Duracao horas, Ciclo dias, Confianca nivel, Score risco → Número decimal
   - Aberto, Classificacao manual, Cluster, Familia operacional,
     Nivel rotulado, Nivel predito (ML), Risco ciclo longo,
     Acao sugerida, Responsavel → Texto
5. Fechar e aplicar.
6. Modelo: uma tabela só. Renomeie para Chamados.

1) MEDIDAS DAX (Nova medida, na tabela Chamados)
================================================================
Total Chamados =
COUNTROWS ( Chamados )

Abertos =
CALCULATE ( COUNTROWS ( Chamados ), Chamados[Aberto] = "Sim" )

Encerrados =
CALCULATE ( COUNTROWS ( Chamados ), Chamados[Aberto] = "Nao" )

Pct Abertos =
DIVIDE ( [Abertos], [Total Chamados] )

Risco Alto Abertos =
CALCULATE (
    COUNTROWS ( Chamados ),
    Chamados[Aberto] = "Sim",
    Chamados[Risco ciclo longo] = "Alto"
)

Abertos N1 =
CALCULATE (
    COUNTROWS ( Chamados ),
    Chamados[Aberto] = "Sim",
    Chamados[Nivel predito (ML)] = "N1"
)

Abertos N3 =
CALCULATE (
    COUNTROWS ( Chamados ),
    Chamados[Aberto] = "Sim",
    Chamados[Nivel predito (ML)] = "N3"
)

Criados =
COUNTROWS ( Chamados )

Encerrados no mes =
CALCULATE (
    COUNTROWS ( Chamados ),
    USERELATIONSHIP ( Chamados[Data resolucao], Calendario[Data] )
)
-- Só crie Encerrados no mes se você fizer um calendário (passo 2).
-- Se não quiser calendário, use o gráfico de colunas agrupadas com
-- Data criacao no eixo e conte Id; o de encerrados use Data resolucao
-- em outro visual, ou pule o calendário e use dois gráficos simples.


================================================================
2) CALENDÁRIO (opcional, só se quiser o gráfico mensal único)
================================================================
Calendario =
CALENDAR ( DATE ( 2025, 10, 1 ), DATE ( 2026, 12, 31 ) )

Relacionamentos:
- Calendario[Data]  *—1  Chamados[Data criacao]     (ativo)
- Calendario[Data]  *—1  Chamados[Data resolucao]   (inativo)

Se não quiser calendário: ignore as medidas Encerrados no mes e
o gráfico mensal único. Use um gráfico só com Data criacao.
